# glibc-provider-sources v0.1.2

`glibc-provider-sources` 0.1.2 fixes a panic when loading a corrupt pack: a
malformed line delta now returns an error instead. Only corrupt or untrusted pack
input was affected; the pack bundled in the crate was never affected.

Published to crates.io through the Trusted Publishing workflow on approval of the
`crates-io` environment. Source tag `v0.1.2` identifies the merge of the release
pull request.

## Changes

- `Sources::parse` and `Sources::from_gzip` return `Err` for a pack whose line
  delta has an empty operation line, or a copy, skip or insert count that
  overflows the base or the delta. Before, such input panicked (a slice index or
  arithmetic overflow) instead of returning an error.
- Found by the new cargo-fuzz `pack` target. The regression test
  `delta::tests::rejects_bad_deltas` covers each case and fails on 0.1.1.
- No other exported API, runtime behavior, source blobs, tables, source pack,
  accepted differences or licenses changed. The unpublished collector and fuzz
  workspace are not part of the package.

## Upgrade

A `glibc-provider-sources = "0.1"` dependency resolves 0.1.2 with `cargo update
-p glibc-provider-sources`. Upgrade if you load packs from outside the crate with
`Sources::parse` or `Sources::from_gzip`; code that uses only `Sources::bundled`
sees no change. Rust 1.90 remains the minimum, and no
dependencies were added.

The 0.1.0 and 0.1.1 archives remain immutable and unchanged.

## Validation and limits

The release pull request ran on its exact head: formatting, workspace tests on
Linux and Windows and on Rust 1.90, Clippy on CI-pinned Rust 1.99, warning-denied
docs, the pack and blob checks, `cargo package` under the size limit, the
replay comparison with all nine pinned compiler images, ClusterFuzzLite, CodeQL,
cargo-deny, zizmor and the release-documentation check. Before the fix was
merged, each of the four fuzz targets ran for five minutes with AddressSanitizer
and no crash.

Fuzzing covers the pack, gzip, delta and table loaders with inputs up to 64 KiB;
it is not a proof that no other panic exists. The collector's parsers are not
fuzzed. Tier 3 remains deferred, and the legal gate on prebuilt compiled-provider
objects remains in force.
